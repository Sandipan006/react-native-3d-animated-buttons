# v1.1.0 fixes: design record

Date: 2026-11-08 · Scope: no breaking changes. The move to the PLAYBOOK Type B layout waits for v2.

## Problems

| Source | Problem |
| --- | --- |
| Issue #4 | No way to turn haptics off. |
| Issue #3 | No way to use a PNG as the icon. |
| Bug | `expo-haptics` is an optional peer, but it was imported at the top of the file. Apps without it crashed on import. |
| Bug | `react-native-svg` was a required peer, but only SVG icons need it. |
| Bug | The 250ms press-lock `setTimeout` was not cleared on unmount. |

## Design

- `haptics?: boolean` (default `true`). When `false`, `expo-haptics` is never called.
- `iconSource?: ImageSourcePropType` renders an `Image` at `iconSize`.
- Icon precedence: `customIcon` > `iconSource` > `customIconSvg` > `icon`. The choice is one pure function, `resolveIcon`.
- `src/haptics.ts` and `src/ButtonIcon.tsx` load their optional peer with `require` inside `try/catch`. Metro treats that as optional. Missing `expo-haptics` means silence; missing `react-native-svg` means SVG icons do not render, with one `__DEV__` warning.
- `AnimatedButton.tsx` now only wires props, the press animation and layout.

## Folder structure

`src/` follows PLAYBOOK §5 (`components/`, `adapters/`, `hooks/`, `interfaces/`, `types/`, `constants/`, `utils/`, `@/` alias). The top level stays legacy (`lib/`, `test-app/`, npm) until v2. `tsconfig.json` type-checks tests; `tsconfig.build.json` emits `lib/` without them.

## Dependencies

Dev tooling stays on the lowest version we support (React 18.2.0, RN 0.73, pinned by RN itself). Only in-range updates were applied. Skipped for v2: RN 0.88, TypeScript 7, Jest 30, Expo 58. `npm audit` shows 0 vulnerabilities.

## Tests (Jest, `jest-expo` preset)

- `resolveIcon.test.ts`: every icon kind and the precedence order.
- `haptics.test.ts`: right style, module missing, device error.
- `AnimatedButton.test.tsx`: `haptics` on/off, disabled/loading silence, `iconSource`, press lock.

## Not in this release

Variants, themes, configurable press depth and font family, and the layout move. They belong to v2.
